# Address Book

A Contact Management System developed using C programming.

## Features
- Add Contact
- Search Contact
- Edit Contact
- Delete Contact
- Display Contacts

## Technologies Used
- C Programming
- Structures
- Pointers
- File Handling

## Project Files
- `main.c` – Main function
- `contact.c` – Contact operations
- `contact.h` – Header file
- `populate.c` – Sample contact population
